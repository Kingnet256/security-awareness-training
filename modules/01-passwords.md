# Module 1 — Passwords & Passphrases

## The one idea
Length beats complexity. A long passphrase you can remember is stronger
than a short "P@ssw0rd!" you can't.

## Why weak passwords fail
Attackers rarely "guess" one password at a time. They:
- Try lists of the most common passwords against many accounts (**password spraying**).
- Reuse passwords leaked from other breaches (**credential stuffing**).
- Run offline cracking against stolen password databases.

A 7-character password with mixed characters can fall in seconds against
modern hardware. A 4-word passphrase can take centuries.

## Do this
- Use a **passphrase**: 4+ random words, e.g. `anchor-quartz-willow-nimbus`.
- Use a **password manager** so every account gets a unique password.
- **Never reuse** a work password anywhere else.
- Turn on **MFA** (see Module 3) — it protects you even if a password leaks.

## Don't do this
- Don't use names, birthdays, `companyname2026`, or keyboard walks (`qwerty`).
- Don't add a `1` or `!` to a weak base word and call it strong.
- Don't share passwords over email or chat.

## 30-second self-check
Ask yourself: *If this exact password leaked tomorrow, how many of my
other accounts would be at risk?* If the answer isn't "zero," fix it.
