# security-awareness-training

Ready-to-run **security awareness** material for small teams and
departments — plain Markdown so you can present it, print it, or drop it
into any LMS/wiki. Written for non-technical staff.

## Modules

1. [Passwords & passphrases](modules/01-passwords.md)
2. [Phishing & suspicious email](modules/02-phishing.md)
3. [Multi-factor authentication (MFA)](modules/03-mfa.md)
4. [Social engineering](modules/04-social-engineering.md)
5. [Reporting an incident](modules/05-reporting.md)

Plus a [10-question knowledge check](quiz.md) with an answer key.

## How to run a 45-minute session

| Time | Segment |
|---|---|
| 0–5 min | Why this matters (recent, real breach headlines) |
| 5–25 min | Modules 1–3 (the everyday habits) |
| 25–35 min | Modules 4–5 (spotting and reporting) |
| 35–45 min | Quiz + open Q&A |

## Field notes

These materials grew out of an internal password-awareness exercise run
in a **closed lab** (a sandbox portal with synthetic accounts — no real
systems or real credentials). The headline finding: a large share of
lab accounts used passwords that fell to a basic dictionary in minutes.
The lesson isn't "hacking is easy" — it's that **passphrases + MFA**
neutralize the entire class of attack. That's the story these modules tell.
